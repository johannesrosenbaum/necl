# NECL benchmarks — methodology

## What we publish

Snapshots under [`bench/published/`](../bench/published/) are meant for GitHub and
customer decks. They are regenerated by:

```bash
bash scripts/publish_bench.sh
```

## Two builds (do not mix)

| Name | Compile | Encoder behaviour | Valid claim |
|------|---------|-------------------|-------------|
| **Deployable** | `-DNEC_LITE_NO_MALLOC` | Stream: Bitpack / Zero / STORE | Sensor MCU / joint MCU |
| **Host** | default | FE_I16 choose-best: compact `0xCE`/`0xCF`, optional `0xCB` LZ, stream+RC | Gateway / lab |

If a README says “NECL 19% on EC2” without **Host**, that is misleading for flash
claims.

## Corpora

| ID | Source | Role |
|----|--------|------|
| `nab_*`, `melbourne_*`, `intel_lab_temp` | Public sensor CSV → int16 (`scripts/fetch_sensor_data.sh`) | Field telemetry |
| `timeseries_i16` | Synthetic AR(1) (same RNG as `codec_ratio`) | Smooth int16 baseline |
| `ticks` | Synthetic u32+i32 ticks | Event stream (host-strong; deployable currently weak) |
| `joint_7axis_1khz_10s` | `scripts/gen_joint_telemetry.py` (**planar** per axis) | **Robotics proxy** (smooth angles, not real robot log) |
| `ucr_*` | UCR archive → int16 | Algo peer / Sprintz |

## Peers

- **heatshrink** — MCU stream / flash peer  
- **Sprintz-Delta** — scalar paper Alg. 1 (int16)  
- **lz4 / miniz** — generic block codecs  

## Metrics

- **Ratio** = `coded / orig` (percent). Lower is better. Roundtrip required.
- **Flash** = `.text` with `arm-none-eabi-gcc -Os` freestanding harness (`scripts/mcu_build.sh`).
- **Host MB/s** = x86_64 proxy on `timeseries_16k` — **not** MCU latency.

## What we do *not* claim (yet)

- Measured CAN/EtherCAT bus utilization %  
- MCU encode latency in µs / cycles on real silicon (QEMU DWT often 0)  
- Real robot joint/torque captures (proxy only)  
- Host compact/LZ ratios as deployable board results
